Understanding Containers

A container is a standard software unit that bundles an application and all its dependencies. This ensures the application runs quickly and reliably across different computing environments.

A Docker container image is a lightweight, standalone, and executable software package that contains everything an application needs to run: code, runtime, system tools, libraries, and settings. At runtime, these images become containers when they run on the Docker Engine.

Containers isolate software from their environment, ensuring they work consistently regardless of the underlying infrastructure, from development to production. They are designed to be:

  • Standard: Docker set the industry standard, making containers portable anywhere.
  • Lightweight: By sharing the host machine's OS kernel, containers don't require a separate OS for each application. This boosts server efficiency and cuts down on server and licensing costs.
  • Secure: Containers provide a safer environment for applications, with Docker offering robust default isolation capabilities.
